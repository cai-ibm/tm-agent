# 1С «Сотрудники» — телефон по ФИО

Открытый HTTP-сервис 1С, plain HTTP, без авторизации, отвечает HTML (не JSON).
`http://192.168.0.20/acc/hs/employees/`

## Эндпоинты

| Запрос | Что отдаёт |
|---|---|
| `/?q=<текст>` | таблица «Наименование / Телефон», строки — ссылки с `guid` |
| `/?q=<текст>&guid=<guid>` | таблица + полная карточка под ней |
| `/?guid=<guid>` | только карточка |

Поля карточки: ФИО рус/англ, дата рождения, телефон, таб.номер, подразделение,
должность, дата приёма, дата увольнения.

Строки парсить регуляркой `<tr><td><a href='?...guid=...'>ФИО</a></td><td>телефон</td></tr>`,
карточку — `<tr><td><b>Поле</b></td><td>значение</td></tr>`. Совпадения подсвечены `<b>`.

## Скрипт

`~/.hermes/skills/devops/employee-phone-1c/scripts/employees.py` (stdlib, без зависимостей):

```bash
python3 .../employees.py "Иванов Александр"          # ФИО + подразделение/должность
python3 .../employees.py "Иванов Александр" --json
python3 .../employees.py --phone "+993 65 05-39-03"  # обратный поиск
python3 .../employees.py --guid <guid>               # карточка целиком
python3 .../employees.py "Мекан" --wide --dept "МТС" # имя + отдел
```

`--wide` обходит лимит 10 строк (перебор `<ФИО> <буква>`, ~31 запрос / 10 с),
`--dept` фильтрует по подразделению из карточки.

## Питфоллы

- **Поиск = ИЛИ**: `q=Иванов Петров` → все Ивановы + все Петровы, неизвестное слово
  игнорируется (`q=qqq 65` → все номера с 65). Клиентски требовать все слова (AND).
- **Лимит 10 строк** на ответ, без признака обрезки — широкий запрос (`q=ов`) молча режется.
- **Пустой `q`** = только форма, без таблицы. Это «не найдено», не ошибка.
- **Телефон ищется как строка с дефисами**: `05-39-03` работает, `99365053903` — нет;
  перебирать форматы и сверять цифры.
- **Телефон грязный**: склейки `+993, 64 052810  62 354681`, мусор `(64) 993 04 97 18` —
  показывать raw, цифры для набора давать только при однозначном формате.
- **Табельный номер поиском не находится** (`q=00313` → пусто) — только по ФИО.
- **Подразделение/должность поиском не ищутся** (`q=ОМТС`, `q=снабжен`, `q=Сменный механик`
  → пусто): они только в карточке. ОМТС в базе = **«Отдел МТС»**, фильтр по `МТС`.
- **Тёзок много**: «Мекан» — 40 человек. Имя без фамилии/отдела ответом не является.
- **Телефон с перестановкой**: `(65) 993  62 20 22` = `+993 (65) 62-20-22` — код страны
  и оператор переставлены, сверять с шаблоном `+993 (XX) XX-XX-XX`.
- ФИО (англ) с диакритикой (`Wasýuhina Tatýana Wiktorowna`); `q=IVANOV` работает.
- **Заполнена дата увольнения → человек уволен**, но остаётся в базе: предупреждать.

## Формат ответа

Один человек → 2–4 строки: ФИО, номер (как в базе + цифры набора), подразделение ·
должность, при наличии «УВОЛЕН ДД.ММ.ГГГГ». Несколько кандидатов → перечислить всех,
не выбирать по похожести. Не найдено → сказать прямо, не подставлять чужих по ИЛИ.
