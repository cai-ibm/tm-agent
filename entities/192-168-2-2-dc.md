# DC — Domain Controller (192.168.2.2)

**DC** (`192.168.2.2`) — основной контроллер домена **cai**. Обнаружен и проаудирован 26.06.2026.

## Параметры

| Параметр | Значение |
|----------|----------|
| **IP** | 192.168.2.2 |
| **Домен** | cai (NetBIOS: CAI) |
| **Учётка** | `cai\hermes` / `Superp@ss2020hermes` |
| **Доступ** | WinRM 5985 (NTLM, pywinrm) |

## Аудит безопасности (26.06.2026)

26.06.2026 проведён полный аудит Active Directory. Результаты отправлены на `sobolevrv@ca-ibm.org` в виде отчёта (AD_Audit_Report.docx + AD_Inactive_Users.docx).

### Проверенные области

- **Политики паролей** — сложность, срок действия, блокировки
- **Привилегированные группы** — Domain Admins, Enterprise Admins, Schema Admins, Backup Operators и др.
- **AdminSDHolder / SDProp** — защищённые админ-группы
- **Service Principal Names (SPN)** — Kerberoastable аккаунты
- **Domain Trusts** — доверительные отношения
- **Inactive/disabled accounts** — заброшенные учётки (90+ дней)
- **Password Never Expires** — учётки с бессрочными паролями
- **Reversible Encryption** — учётки с обратимым шифрованием паролей
