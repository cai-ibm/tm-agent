# Сервер 94.130.51.161 (Hetzner VPS)

Основной сервер-шлюз. Хостит nginx reverse proxy, n8n, OnlyOffice Document Server, Paperless-ngx, **OpenConstructionERP**. Внешняя точка входа для всех веб-сервисов организации.

## Сервисы

### Nginx (reverse proxy)
Основной entry point. Проксирует трафик на внутренние сервисы:

| Домен | Проксируется на | Сервис |
|-------|-----------------|--------|
| `n8n.ca-ibm.org` | localhost:5678 | n8n |
| `ofds.ca-ibm.org` | localhost:8080 | OnlyOffice Document Server |
| `stargate.ca-ibm.org` | [[stargate-ca-ibm-org]] | Nextcloud |
| `ocerp.ca-ibm.org` | localhost:8082 | [[openconstructionerp]] |
| `doc.ca-ibm.org` | localhost:8010 | Paperless-ngx |

### n8n (порт 5678)
Платформа автоматизации рабочих процессов.
- URL: `https://n8n.ca-ibm.org/`
- MCP-сервер: `https://n8n.ca-ibm.org/mcp-server/http` (JWT-аутентификация)
- Конфиг MCP: `~/.hermes/config.yaml`
- Управление: навык `n8n-workflow-automation`

### OnlyOffice Document Server (порт 8080)
Docker-контейнер, порт 0.0.0.0:8080→80.
- URL: `https://ofds.ca-ibm.org/`
- Обновлён 08.05.2026: 9.1.0 → 9.3.1
- RabbitMQ стартует сам (фикс в 9.3.1)
- JWT-секрет: задан
- Интегрирован с [[stargate-ca-ibm-org]]

### OpenConstructionERP (порт 8082)
Развёрнут 25.05.2026 в Docker Compose на 8082.
- URL: `https://ocerp.ca-ibm.org/`
- Версия: 4.9.1
- Репозиторий: `/opt/OpenConstructionERP/`
- Docker Compose: `docker-compose.quickstart.yml`
- Сборка требовала `NODE_OPTIONS=--max-old-space-size=4096` (OOM без него)
- Let's Encrypt: ocerp.ca-ibm.org, до 23.08.2026
- Подробнее: [[openconstructionerp]]

### Paperless-ngx (порт 8010)
Docker-контейнеры (app + postgres + redis), порт 127.0.0.1:8010→8000.
- URL: `https://doc.ca-ibm.org/`
