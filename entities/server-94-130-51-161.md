# Сервер 94.130.51.161 (Hetzner VPS)

Основной сервер-шлюз. Хостит Nginx Proxy Manager, n8n, OnlyOffice Document Server, Paperless-ngx. Внешняя точка входа для всех веб-сервисов организации. Теперь также имеет интерфейс в локальной сети CA-IBM.

### ⚠️ Двойной default gateway
Оба интерфейса имеют default route с metric 100. Часть внешнего трафика может уходить через MikroTik (192.168.2.1). Нужно поднять metric на ens37 до 200+.

## Nginx Proxy Manager (вместо системного nginx)

Системный nginx (apt) **остановлен и отключён** (systemctl disable nginx). Вместо него — Nginx Proxy Manager в Docker с `network_mode: host`.

- **Путь**: `/opt/nginx-proxy-manager/docker-compose.yml`
- **Веб-интерфейс**: `http://94.130.51.161:81` или `http://192.168.2.37:81` (изнутри сети)
- **Admin**: `sobolevrv@ca-ibm.org` / `changeme` (⚡ сменить пароль!)
