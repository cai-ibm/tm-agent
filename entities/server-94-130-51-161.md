### ⚠️ Policy routing (асимметричная маршрутизация)
Пакеты с подсетей 192.168.30.0/24 и 192.168.31.0/24 приходят на ens37, но ответ может уйти через default gateway ens34. Решение — policy routing:

- Таблица `ens37_rt` (100): default + 192.168.0.0/16 + 10.10.0.0/16 через 192.168.2.1 dev ens37
- Правило: `from all iif ens37 lookup ens37_rt priority 100`
- Автозапуск: netplan + systemd `ens37-policy-routing.service`

⚠️ Дополнительно: с сервера недоступна подсеть 192.168.31.0/24 — MikroTik её не маршрутизирует. Но обратный трафик с тех подсетей должен проходить.

## Nginx Proxy Manager (вместо системного nginx)

Системный nginx (apt) **остановлен и отключён** (systemctl disable nginx). Вместо него — Nginx Proxy Manager в Docker с `network_mode: host`.

- **Путь**: `/opt/nginx-proxy-manager/docker-compose.yml`
- **Веб-интерфейс**: `http://94.130.51.161:81` или `http://192.168.2.37:81` (изнутри сети)
- **Admin**: `sobolevrv@ca-ibm.org` / `changeme` (⚡ сменить пароль!)
