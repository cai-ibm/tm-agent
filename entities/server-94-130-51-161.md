# Сервер 94.130.51.161 (Hetzner VPS)

Основной сервер-шлюз. Хостит nginx reverse proxy, n8n, OnlyOffice Document Server. Внешняя точка входа для всех веб-сервисов организации.

## Основные параметры

| Параметр | Значение |
|----------|----------|
| **IP** | 94.130.51.161 |
| **Провайдер** | Hetzner |
| **ОС** | Ubuntu 24.04 |
| **Ядро** | 6.8.0-111 |
| **Доступ** | root, SSH |

## Сервисы

### Nginx (reverse proxy)
Основной entry point. Проксирует трафик на внутренние сервисы:

| Домен | Проксируется на | Сервис |
|-------|-----------------|--------|
| `n8n.ca-ibm.org` | localhost:5678 | n8n |
| `ofds.ca-ibm.org` | localhost:8080 | OnlyOffice Document Server |
| `stargate.ca-ibm.org` | [[stargate-ca-ibm-org]] | Nextcloud |
| `ocerp.ca-ibm.org` | OpenConstructionERP | ERP |

Конфигурация: навык `n8n-workflow-automation` (секция nginx), Obsidian: [[Сервер 94.130.51.161 (nginx)]].

### n8n (порт 5678)
Платформа автоматизации рабочих процессов.
- URL: `https://n8n.ca-ibm.org/`
- MCP-сервер: `https://n8n.ca-ibm.org/mcp-server/http` (JWT-аутентификация)
- Конфиг MCP: `~/.hermes/config.yaml`
- Управление: навык `n8n-workflow-automation` (13 инструментов: поиск, создание, запуск, публикация workflow)

### OnlyOffice Document Server (порт 8080)
Сервер редактирования документов.
- URL: `https://ofds.ca-ibm.org/`
- Обновлён 08.05.2026: версия 9.1.0 → 9.3.1
- **Docker-контейнер**
- После обновления до 9.3.1 RabbitMQ больше не требует ручного запуска после перезагрузки
- JWT-секрет: задан
- Интегрирован с [[stargate-ca-ibm-org]] (Nextcloud)

Навыки Hermes:
- `onlyoffice-troubleshooting` — диагностика проблем (read-only .docx и др.)
- `onlyoffice-rabbitmq-fix` — ⚠️ DEPRECATED, только для версий < 9.3.1
