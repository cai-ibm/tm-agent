## Сеть

- Внутренняя сеть Docker (bridge)
- Kong на порту 8000 — точка входа в API Supabase
- Supavisor на портах 5432 (session mode), 6543 (transaction mode)
- Внешняя точка: `http://192.168.2.34:8000`
