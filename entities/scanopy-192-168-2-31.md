# Scanopy

**Scanopy** — open-source инструмент для автоматической документации сети. Сканирует инфраструктуру (SNMP, LLDP, ARP, Docker) и строит 4 вида топологии: L2 (физическая), L3 (логическая), Workloads (нагрузки), Applications (приложения). 5.1k звёзд на GitHub. Лицензия AGPL-3.0.

## Возможности

- **Автоматическое обнаружение** — сканирует сеть, не требует агентов на устройствах
- **230+ определений сервисов** — автоопределение БД, веб-серверов, контейнеров, сетевого оборудования
- **4 вида топологии** — L2 (физическая), L3 (логическая), Workloads, Applications
- **Распределённое сканирование** — демоны в разных сегментах сети
- **Docker & SNMP** — нативное обнаружение контейнеров и сетевого оборудования
- **Плановые ресканы** — документация остаётся актуальной
- **Multi-user + RBAC** — управление организациями, ролевой доступ

## При первом входе

1. Открыть `http://192.168.2.31:60072`
2. Создать учётную запись администратора
3. Демон автоматически начнёт сканирование сети
4. Через несколько минут появятся L2/L3 топологии
