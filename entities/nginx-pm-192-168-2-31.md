# Nginx Proxy Manager — 192.168.2.31

Отдельная ВМ с Nginx Proxy Manager для централизованного управления reverse proxy, SSL-сертификатами и проксированием трафика. Замена/дополнение ручного nginx на [[server-94-130-51-161]].

## Установка

Docker Compose:

```yaml
services:
  app:
    image: 'jc21/nginx-proxy-manager:latest'
    restart: unless-stopped
    ports:
      - '80:80'
      - '81:81'
      - '443:443'
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
```
