# HT2 — WG Easy VPN

**HT2** (`ht2.ca-ibm.org`) — VPN-сервер на базе WG Easy (WireGuard). Развёрнут в Docker на 188.124.56.126.

## Параметры

| Параметр | Значение |
|----------|----------|
| **IP** | 188.124.56.126 |
| **Хостинг** | Hetzner |
| **ОС** | Ubuntu 24.04 |
| **Пользователь** | `cai` (sudo) |
| **Пароль** | `Superp@ss2020cai` |
| **Доступ** | Через sshpass |

## Развёртывание

- **WG Easy** (WireGuard) в Docker: порт 51820/udp, веб-интерфейс 51821/tcp
- **Nginx Proxy Manager** на Докер1 (94.130.51.161): прокси-хост `ht2.ca-ibm.org:51821` → `http://188.124.56.126:51821`
- **UFW** настроен: 22/tcp (только 94.130.51.188), 51821/tcp (только 94.130.51.161), 51820/udp (всем)

## Ежедневная перезагрузка

Сервер перезагружается каждый день в 00:00 через cron Hermes Agent:

```
Cron job: ht2-vpn-reboot (id: 17b19a78056b)
Schedule: 0 0 * * *
Prompt: перезагрузка 188.124.56.126 через sshpass + sudo reboot
```

После перезагрузки агент проверяет доступность сервера по SSH (до 2 минут ожидания).

## Проблемы

### Пароль SSH не работает (19.06.2026)

При плановой перезагрузке 19.06.2026 в 00:10 пароль `Superp@ss2020cai` был **отклонён сервером**. Диагностика:
- ✅ Хост доступен по ICMP (ping 10.8ms)
- ✅ Порт 22 открыт (SSH)
- ✅ Сервер принимает password-аутентификацию (метод `password` разрешён)
- ❌ **Пароль не подходит** — стабильно `Permission denied`

Пользователи `root`, `admin`, `ubuntu`, `deploy`, `user`, `sysadmin` — все не принимают этот пароль.
**Статус:** требуется уточнение пароля или настройка SSH-ключа.
