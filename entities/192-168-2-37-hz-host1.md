## Docker Exporter (cgroup v2 fix)

**Дата:** 2026-07-01
**Проблема:** На Ubuntu 24.04 (cgroup v2) поле кеша в memory_stats называется `inactive_file`, а не `total_inactive_file` или `cache`. Старый экспортёр брал `memory_stats.usage` целиком, включая ~3.8 GiB page cache.
**Решение:** Обновлён `/app/exporter.py` в контейнере `docker-exporter` — функция `get_working_set()` теперь пробует все известные имена поля кеша (`total_inactive_file`, `inactive_file`, `cache`). Memory working set n8n: 5.4 GiB → 1.61 GiB (совпадает с `docker stats`).
