## Связи (типовые 1С)
- **Справочник → Справочник**: поле `_ParentIDRRef`, `_OwnerIDRRef`, `_FldXXXRRef` (binary(16) — GUID ссылки)
- **Справочник → Перечисление**: поле `_FldXXX_TYPE` + `_FldXXX_RTRef` + `_FldXXX_RRRef` (типизированная ссылка)
- **Документ → Справочник**: `_Fld4351RRef`, `_Fld4352RRef` и т.д.
- **Документ → Документ**: `_Fld4360_RRRef`
- **Журнал → Документ**: `_DocumentTRef` (тип документа) + `_DocumentRRef` (ссылка на документ)
- **Регистр → Справочник**: поле `_FldXXXRRef`
