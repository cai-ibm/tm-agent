## UNGM Parser — настройка на Hermes Agent

Источник: https://github.com/cai-ibm/maki-obsidian (папка `scripts/ungm/`)

### Установка

- Венв: `~/.hermes/scripts/ungm_venv/` (Python 3.12, lxml + PyMuPDF + python-docx + openpyxl + requests)
- Скрипты: `~/.hermes/scripts/ungm_parser/` (скопированы из `maki-obsidian/scripts/ungm/`)
- Notion API: бот **maki-hermes** (`ntn_...`), версия `2025-09-03`
- DeepSeek API: модель `deepseek-chat`, ключ `sk-10f...25e3`

### Cron

- Задача Hermes: `UNGM Parser — мониторинг тендеров`
- Расписание: `0 12 * * 1-5` (пн–пт, 12:00 UTC)
- Доставка: Telegram homechannel
- На новых лотах: краткая сводка с названием, страной, бюджетом, ссылкой
- Если новых нет: "Новых лотов нет"

### Базы Notion

| База | ID | Назначение |
|------|----|-----------|
| Лоты UNGM | `65e1bd93-18ab-4dc2-a092-ee4fd66cdd08` | Куда пишем результаты |
| Коды UNSPSC | `3b74e69b-48c7-4bbe-af26-6ed2dfc69388` | 46 кодов раздела D (строительство) |
| Страны UNGM | `07a61f59-b472-4cb3-b4e5-8a33e1141396` | Узбекистан, Казахстан, Киргизстан |
| Ключевые слова UNGM | `0dcf72ce-4a5d-4a34-8d60-45b48652cca9` | 43 активных слова с весами 1-3 |

### Изменения относительно оригинала

1. **Название страницы в Notion** — теперь формат `{reference} — {country}` вместо полного названия лота
2. **Переменные окружения** — ключи пока в `config.py` (не вынесены в `.env`)

### Процесс

1. Читает коды UNSPSC и страны из Notion
2. Ищет лоты на UNGM (POST, парсинг lxml, пагинация до 10 страниц)
3. Фильтр по ключевым словам (сумма весов >= 2)
4. AI-верификация через DeepSeek (отсев ложных срабатываний)
5. Дедупликация по URL
6. Для каждого нового: загрузка деталей → извлечение документов (PDF/DOCX/XLSX) → перевод названия → экспертный анализ → запись в Notion
