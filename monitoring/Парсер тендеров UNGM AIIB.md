# Парсер тендеров (UNGM + AIIB)

## Архитектура

```
/root/.hermes/scripts/ungm_parser/
├── config.py          — API-ключи, ID баз Notion, маппинги стран
├── main.py            — оркестратор: запуск обеих площадок
├── ungm_client.py     — парсинг UNGM (POST → HTML → lxml)
├── aiib_client.py     — парсинг AIIB (curl → JSON → lxml)
├── notion_client.py   — чтение/запись/обновление в Notion
├── keyword_filter.py  — фильтрация по ключевым словам + AI-верификация
├── analyst.py         — DeepSeek: перевод, анализ, верификация
└── ungm_venv/         — виртуальное окружение
```

## Площадки

### UNGM (ungm.org)
- **Тип:** открытые тендеры (procurement notices)
- **Метод:** POST `ungm.org/Public/Notice/Search` с JSON payload
- **Ответ:** HTML-таблицы, парсинг через lxml
- **Фильтр:** только по странам (UNSPSC отключён — пропускает кросс-категорийные лоты)
- **Пагинация:** до 10 страниц
- **Детали:** `ungm.org/Public/Notice/{noticeId}` — HTML → описание + документы
- **Документы:** PDF/DOCX/XLSX, извлечение текста через PyMuPDF/python-docx/openpyxl

### AIIB (aiib.org)
- **Тип:** инвестиционные проекты (не тендеры)
- **Метод:** GET `aiib.org/en/projects/list/.content/all-projects-data.js`
- **Ответ:** JS-файл с JSON-массивом (438 проектов)
- **Фильтр:** по странам (через маппинг русских → английских названий) + по статусу (Approved и Proposed)
- **Детали:** статический HTML-файл проекта, парсинг через lxml
- **Документы:** PDF-файлы на странице проекта

## База Notion «Лоты»

### Структура свойств

| Свойство | Тип | Описание |
|----------|-----|----------|
| Название лота | title | `{reference} — {страна}` |
| Полное название | rich_text | Перевод названия на русский (DeepSeek) |
| Организация | rich_text | UN-агентство или "Asian Infrastructure Investment Bank (AIIB)" |
| Дата размещения | date | Дата публикации |
| Дата парсинга | date | Когда спарсено |
| Дата завершения | date | Дедлайн (только для UNGM; для AIIB не заполняется) |
| Ссылка | url | Прямая ссылка на лот/проект |
| Страна | select | Страна-бенефициар |
| Площадка | select | UNGM или AIIB |
| Бюджет | rich_text | Сумма финансирования |
| Статус | select | Новый / В анализе / Экспертиза / Завершён |
| Риск-уровень | select | Низкий / Средний / Высокий |

### История изменений базы
- Было: «Лоты UNGM» → Стало: **«Лоты»**
- Было: «Ссылка на UNGM» → Стало: **«Ссылка»**
- Добавлено: **«Площадка»** (select: UNGM, AIIB)
- Было: Бюджет (number) → Стало: **Бюджет (rich_text)**

## Фильтрация

### Ключевые слова (из Notion, база «Ключевые слова UNGM»)
- Каждое слово: русское название + английский перевод + вес (1-3) + категория
- Релевантность = сумма весов совпавших слов в заголовке
- Порог: `MIN_RELEVANCE >= 2`
- Проверяются и русское слово, и английский перевод (поле «Перевод»)
- AI-верификация: DeepSeek отсеивает ложные срабатывания (RELEVANT / NOT_RELEVANT)

### Фильтры по площадке

**UNGM:**
- Только фильтр по ключевым словам (одинаковый для обеих площадок)

**AIIB:**
- Статус: **Approved** или **Proposed** (On Hold, Terminated/Cancelled исключены)
- Фильтр по секторам отключён — используется общий фильтр ключевых слов
- Ключевые слова работают через английские переводы (поле «Перевод» в базе Notion)

## Анализ (DeepSeek)

На каждый новый лот — 3 вызова DeepSeek API:
1. **translate_title** — перевод названия на русский (temperature=0.1, max_tokens=200)
2. **analyze_lot** — экспертный анализ: финансы, риски, рекомендация
3. **verify_relevance** — бинарный классификатор (RELEVANT / NOT_RELEVANT)

## Обновление существующих лотов

При повторном запуске:
1. Загружаются все существующие лоты из Notion
2. Для каждого URL проверяется, есть ли он уже в базе
3. Если есть — сравниваются поля: Название лота, Полное название, Организация, Дата размещения, Страна, Площадка, Ссылка, Бюджет
4. Для AIIB поле «Дата завершения» не сравнивается и не обновляется
5. Если изменились — патчятся только изменившиеся поля + обновляется дата парсинга
6. Если не изменились и уже сегодня парсили — пропускается (без API-вызова)
7. Для существующих лотов AIIB также выполняется перевод названия на русский

## Бюджет

- **AIIB:** берётся из `approved_funding` или `proposed_funding` (чистое значение, без префиксов)
- **UNGM:** извлекается из текста описания + первых 3 документов через `_extract_budget()` (regex: суммы в USD/EUR/$)
- Если не найден — остаётся пустым

## Важные замечания

1. **UNGM — не REST API.** Возвращает HTML из POST-запросов. Парсер хрупкий к изменениям HTML.
2. **AIIB — проекты, не тендеры.** Нет дедлайнов, UNSPSC, агентства закупок. Только инвестиционные проекты.
3. **AIIB JSON с trailing comma.** JS-файл содержит `,` перед `]` — удаляется через regex перед парсингом.
4. **DeepSeek — китайская модель.** При переводе может выдавать китайские иероглифы. Промпт на русском с явным запретом CJK.
5. **API-ключи в plaintext** в `config.py`. Для публичных репозиториев вынести в `.env`.
6. **Notion API v2025-09-03** — использует `/data_sources/` endpoints (connected databases).
7. **Страны из Notion на русском.** Для AIIB нужен маппинг на английские названия.
8. **Ключевые слова — только ручной ввод.** Не добавлять автоматически. Использовать только те, что пользователь ввёл в Notion.
9. **AIIB — статусы:** Approved и Proposed (On Hold, Terminated/Cancelled исключены).
10. **AIIB — дата завершения** не заполняется; это инвестиционные проекты, не тендеры.
