# TMCELL Мониторинг

Автоматическая проверка всех TMCELL-аккаунтов каждые 30 минут.

## Механизм
- **Скрипт:** `~/.hermes/scripts/tmcell_monitor.py`
- **Расписание:** system crontab (`*/30 * * * *`)
- **Уведомления:** Telegram Bot API (напрямую, без LLM — 0 токенов)
- **Протокол:** [SILENT] — уведомления только при проблемах

## Пороги

- Остаток трафика < 1 ГБ → alert
- Срок пакета < 24 часов → alert
- Баланс отрицательный → alert
- **Баланс пополнен** (прирост > 1 manat) → уведомление `💰 пополнения` *(добавлено 2026-09-28)*
- **Аккаунт не проверяется** 3 запуска подряд (ошибка входа / исчерпанный таймаут) → alert *(добавлено 2026-09-28)*

Блоки сообщения: `🚨 алерты` · `💰 пополнения` · `✅ улучшения` · `⚠️ ошибки`

## Принципы
- Python requests (не curl — Gozleg Protection)
- Игнорировать SMS/минуты (без остатка в Gb/Mb)
- Суммировать остатки по всем активным пакетам
- Берётся самая дальняя дата среди всех пакетов
- **Ошибки входа/фантомные сессии алертятся только после 3 неудачных запусков подряд** — единичные сбои молча пишутся в лог, не спамим в чат (при восстановлении приходит «✅ снова проверяется»)
- **State обновляется на каждом запуске для каждого аккаунта** (`prev_balance`, `prev_gb`, `fail_count`) — иначе триггер пополнения баланса не работает. Схема state = 2
- **Тест без отправки в Telegram:** `TMCELL_DRY_RUN=1 python3 ~/.hermes/scripts/tmcell_monitor.py`
