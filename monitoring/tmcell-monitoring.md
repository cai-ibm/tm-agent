# TMCELL Мониторинг

Автоматическая проверка всех TMCELL-аккаунтов каждые 30 минут.

## Механизм
- **Скрипт:** `~/.hermes/scripts/tmcell_monitor.py`
- **Расписание:** system crontab (`*/30 * * * *`)
- **Уведомления:** Telegram Bot API (напрямую, без LLM — 0 токенов)
- **Протокол:** [SILENT] — уведомления только при проблемах

## Пороги
- Остаток трафика < 1 ГБ → alert
- Срок пакета < 24 часов → alert

## Принципы
- Python requests (не curl — Gozleg Protection)
- Игнорировать SMS/минуты (без остатка в Gb/Mb)
- Суммировать остатки по всем активным пакетам
- Берётся самая дальняя дата среди всех пакетов
- **Ошибки входа/фантомные сессии НЕ алертятся** — молча пишутся в лог, в Telegram не уходят (штатная ситуация, не спамим в чат)
