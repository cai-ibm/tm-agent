## UNGM Parser

Источник: `maki-obsidian/scripts/ungm/`

**Назначение:** Мониторинг строительных тендеров ООН (UNGM) для стран Центральной Азии.

### Компоненты

| Модуль | Файл | Назначение |
|--------|------|-----------|
| Оркестратор | `main.py` | Основной цикл: поиск → фильтр → AI → запись |
| Клиент UNGM | `ungm_client.py` | Поиск лотов (API, lxml, пагинация до 10 стр), загрузка деталей, извлечение документов (PDF/DOCX/XLSX) |
| Фильтр ключевых слов | `keyword_filter.py` | 43 слова (веса 1-3, порог ≥2), AI-верификация DeepSeek |
| Аналитик | `analyst.py` | DeepSeek: перевод названия, экспертный анализ (финансы, риски, рекомендации) |
| Notion-клиент | `notion_client.py` | Чтение UNSPSC/стран/слов, дедупликация, запись лотов |
| Конфиг | `config.py` | ID баз Notion, ключи API, маппинг стран → ID UNGM |

### Процесс

1. **Notion** → читает коды UNSPSC (46 кодов) + страны (Узбекистан, Казахстан, Киргизстан)
2. **UNGM** → поиск лотов по странам (без фильтра по UNSPSC)
3. **Ключевые слова** → отсев по весам ≥2 (из Notion)
4. **AI-верификация** → DeepSeek отсеивает ложные срабатывания
5. **Дедупликация** → сверка с Notion
6. **Новый лот** → загрузка деталей → извлечение документов → перевод → экспертный анализ → запись в Notion

### Cron

- Расписание: `0 12 * * 1-5` (пн–пт, 12:00 UTC)
- Доставка: Telegram
- Сообщение: краткая сводка или «Новых лотов нет»
